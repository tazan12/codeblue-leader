코드블루 리더 1.0.4 — 설치 및 강사 창 사용 안내
================================================

[설치]
1. 이 압축 파일을 원하는 폴더에 "모두 압축 풀기" 합니다.
2. CodeBlueLeader-Setup-1.0.4-x64.exe 를 더블클릭합니다.
3. "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   (코드 서명 인증서가 없는 교육용 프로그램이라 나오는 경고입니다.)
4. 설치 위치를 확인하고 [설치]를 누릅니다. 관리자 권한 없이 현재 사용자 계정에 설치됩니다.
5. 바탕화면·시작 메뉴의 "코드블루 리더" 바로가기로 실행합니다.
   (이전 버전이 설치돼 있으면 그대로 덮어 설치됩니다.)

[사양]
- Windows 10 / 11, 64비트(x64)
- 인터넷 없이 동작합니다(사진·영상·음성·리듬 학습 포함).
- 화면 1280 × 800 이상 권장, 스피커 또는 이어폰 권장

[강사 창 — 듀얼 모니터 수업]
- 상단 [강사 창 열기]를 누르면 강사 콘솔이 별도 창으로 열립니다.
  보조 모니터(노트북 화면 등)가 연결돼 있으면 자동으로 그쪽에 뜹니다.
- 학생 화면(프로젝터)에는 강사 조작이 보이지 않고, 디브리핑에만 기록됩니다.
- 강사 콘솔 4개 탭
  · 진행 조종: 실제 리듬·활력징후, ROSC 유도·재정지·술기 실패, 리듬·혈압·원인 변경,
    돌발 상황(정맥로 빠짐·패드 떨어짐·기관내관 빠짐·충전 오류·팀원 이탈·보호자 등장·약물 재고 없음),
    학생 화면에 상황 알림/코칭 힌트 보내기, 진행 속도(0.5~3배), 힌트 켜기·끄기
  · 관찰·평가: 압박 분율·중단·교대·에피 간격 등 실시간 지표, 핵심 행동 체크리스트(자동 기록),
    잘한 점/개선점 장면 표시, 비기술적 역량(리더십·의사소통 등) 1~5점 평가
  · 디브리핑: 케이스 종료 시 점수 내역과 PEARLS 흐름의 질문 안내를 자동 생성
  · 수업 기록: 팀(조) 이름 지정, 최근 결과를 엑셀로 복사

[마우스가 하나일 때 — 조작 방법]
한 PC에 모니터가 두 대여도 마우스 커서는 하나입니다. 다음 중 편한 방법을 쓰세요.
 1) 단축키 (가장 간단)
    - 강사 창이 선택돼 있을 때: R ROSC · V VF · P PEA · A 무수축 · F 술기 실패(두 번 눌러 실행)
      C 지원팀 도착 · H 원인 교정 · Space 일시정지 · G/B 장면 표시 · 1~4 탭 이동
    - 학생 화면을 클릭해 둔 상태에서도: Ctrl + Alt + 같은 글자
      (강사 창이 열려 있는 동안만 동작) → 무선 키보드를 강사가 들고 있으면 편합니다.
 2) 휴대폰·태블릿으로 조종 (추천)
    - 강사 창의 [휴대폰 연결 켜기] → 표시되는 QR 코드를 휴대폰 카메라로 찍습니다.
    - PC와 휴대폰이 같은 Wi-Fi(공유기)에 있어야 합니다. 4자리 PIN으로 보호됩니다.
    - 처음 켤 때 "Windows 보안 경고(방화벽)" 창이 뜨면 [개인 네트워크]에 체크하고 [허용].
    - 학생은 PC 마우스로 시뮬레이션을, 강사는 휴대폰으로 상황을 조종합니다.
 3) 역할 분담
    - 학생 1명이 마우스 조작(기록·실행 담당), 팀 리더 학생은 말로 지시하고,
      강사는 단축키나 휴대폰으로 개입합니다.

[웹 버전]
- 설치 없이 브라우저에서: https://tazan12.github.io/codeblue-leader/
  (웹에서도 [강사 창 열기]로 같은 브라우저의 새 창에 강사 콘솔이 열립니다. 휴대폰 조종은 설치판 전용)

[사용자 정의 케이스]
- 케이스 선택 화면 아래 '사용자 정의 케이스'에서 새 케이스를 만들고 저장합니다.
- 기존 케이스를 틀로 불러오기, 시나리오 이벤트(시작 후/ROSC 후 N초), 팀 구성, 학습 목표·디브리핑 포인트 설정.
- [공유] → 코드 복사 후 다른 PC의 [가져오기]에 붙여넣으면 같은 케이스가 만들어집니다(.json 파일도 가능).

[사용 팁]
- F11 전체 화면 / Ctrl + 와 Ctrl - 확대·축소 / Ctrl 0 화면에 맞춤(작은 화면에서는 자동 축소)
- 케이스 기록과 학습 진도는 각 PC에 저장됩니다.

[제거]
Windows 설정 → 앱 → 설치된 앱 → "코드블루 리더" 제거

[안내]
- 2025 한국 심폐소생술 가이드라인(성인 전문소생술)을 바탕으로 만든 교육용 시뮬레이션입니다.
  실제 진료 지침이나 공식 자격 과정을 대신하지 않습니다.
- 인물·장비 사진, 배경 영상, 음성은 AI로 생성한 가상 자료입니다.
