# 코드블루 리더 (CodeBlue Leader)

병동 심정지·부정맥 상황에서 **팀 리더 역할**을 훈련하는 교육용 시뮬레이터입니다. 2025 성인 전문소생술 가이드라인 값을 바탕으로 만들었습니다.

- **웹 버전 (설치 없이 바로 실행):** https://tazan12.github.io/codeblue-leader/
- **Windows 설치판:** [최신 릴리스에서 내려받기](https://github.com/tazan12/codeblue-leader/releases/latest) → `CodeBlueLeader-Setup-x.y.z-x64.exe`

## 주요 기능
- **케이스 11종** — 심실세동·무맥성 VT·Torsades·무수축·PEA(원인 무작위)·증상 서맥·3도 방실차단·불안정/안정 SVT·빠른 심방세동·맥박 있는 VT. 기초·심화·평가 모드.
- **팀 리더 시뮬레이션** — 실사 병실 위에서 팀원 5명에게 업무를 지시합니다. 실시간 ECG·SpO₂·카프노그래피, 제세동기·조율기(SYNC 표식 포함), 음성 대화를 갖췄습니다.
- **현실적인 CPR 품질** — 압박 중단 타이머(10초 경고)와 압박자 피로를 반영합니다. 1–2분 뒤 깊이가 줄어 2분마다 교대해야 합니다.
- **ROSC 이후 처치 안내** — ROSC를 선언하면 [목표] 탭이 순서대로 된 처치 목록으로 바뀝니다(감시장치 → 산소 → 환기 → 혈압 → 12유도 → 체온 조절). 항목마다 바로 누를 수 있는 버튼이 있고, 다음에 할 일이 강조됩니다.
- **호흡·맥박 확인 결과 카드** — 사정이 끝나면 맥박과 호흡이 있는지 바로 보여 줍니다. 평가 모드가 아니면 다음 행동도 안내합니다.
- **채점·디브리핑** — CPR 질, 압박자 교대, 기도·환기, 전기치료, 약물, 판독, 소생 후 목표를 채점합니다. 2분 주기 표와 타임라인도 볼 수 있습니다.
- **강사 콘솔(별도 창)** — 강사 창은 4개 탭으로 되어 있습니다.
  - 진행 조종: 돌발 상황 넣기, 상황 알림·코칭 힌트, 속도, 리듬 변경
  - 관찰·평가: 실시간 지표, 체크리스트, 장면 표시, 비기술적 역량 평가
  - 디브리핑: PEARLS 질문을 자동으로 만듭니다
  - 수업 기록: 팀별 결과, 엑셀 복사
- **사용자 정의 케이스 설계실** — 시나리오 이벤트, 팀 구성, 학습 목표를 정할 수 있고, 코드나 파일로 공유합니다.
- **심전도 리듬 학습** — 이론, 리듬 도감, 캘리퍼, 비교, 판독 연습, 카프노그래피·고칼륨·패드 위치·조율 포획, 참고 문헌을 담았습니다.
- **알고리즘 요약 흐름도** — 첫 대응, 충격/비충격 리듬, 서맥, 빈맥, ROSC 이후, 5H·5T.

## 듀얼 모니터 수업
학생 화면은 프로젝터에 전체화면(F11)으로 띄우고, **[강사 창 열기]** 창은 노트북 화면에 둡니다. 마우스가 하나이므로 강사는 다음 중 하나로 조작합니다.
- **휴대폰·태블릿 (설치판):** 강사 창에서 [휴대폰 연결 켜기]를 누르고 QR을 찍습니다. 같은 Wi-Fi에서 PIN으로 보호됩니다.
- **단축키:** 강사 창에서 R·V·P·A·F는 두 번 눌러 실행하고, C·H·Space·G·B는 한 번 누릅니다. 설치판에서는 학생 화면을 클릭해 둔 상태에서도 `Ctrl+Alt+글자`로 실행됩니다.
- **웹 버전:** 같은 브라우저의 새 창으로 강사 콘솔이 열리고 자동으로 연결됩니다.

## 폴더 구조
```
src/            화면·로직 조각 (head.html, *.css, *.js) 과 내장 자료(src/assets: 사진·영상·음성 base64)
tools/build.py  조각을 합쳐 dist/web/index.html, inst.html 을 만들고 app/ 에 복사
app/            Windows 설치판(Electron): main.js, preload.js, package.json, 아이콘, 설치 안내
.github/        main 푸시 → 웹 버전 자동 배포(gh-pages), v* 태그 → 설치판 자동 빌드·릴리스
```

## 직접 빌드
```bash
python tools/build.py                 # 웹: dist/web/index.html
cd app && npm ci && npx electron-builder --win nsis --x64   # 설치판: app/dist/*.exe
```
새 버전 배포: `app/package.json` 의 version 을 올려 main 에 푸시한 뒤, GitHub에서 **Releases → Draft a new release** 로 `vX.Y.Z` 릴리스를 게시하면 설치판이 자동으로 빌드되어 릴리스에 붙습니다.

## 알림
- 교육용 시뮬레이션입니다. 실제 진료 지침, 의학적 판단, 공식 자격 과정을 대신하지 않습니다. 생리 반응과 확률은 학습을 위해 단순화했습니다.
- 인물·장비 사진, 배경 영상, 음성은 AI로 생성한 가상 자료입니다.
- 기록과 사용자 정의 케이스는 각 PC·브라우저에만 저장됩니다.
- 경민대학교 간호학과 교육용으로 제작되었습니다.
